# Supported versions and branches

| Minecraft | Fabric | Forge | Branch | Notes |
| --- | --- | --- | --- | --- |
| **1.20.1** | yes | yes | `main`, `1.20.1` | Flagship LTS line (Monifactory / 1.20.1 packs) |
| **1.20.2** | yes | yes | `1.20.2` | 4-arg screen rendering API |
| **1.20.4** | yes | — | `1.20.4` | Modern 1.20.4 Fabric |
| **1.20.6** | yes | — | `1.20.6` | First Data Components & Java 21 line |
| **1.21.1** | yes | — | `1.21.x`, `1.21.1` | Modern 1.21.x flagship line |
